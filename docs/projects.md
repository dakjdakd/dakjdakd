[GitHub](https://github.com/dakjdakd/openwiki)

AI-powered GitHub repository analysis and technical Wiki generation.

- 🎯 Role: Full-stack and AI orchestration

- ✨ Highlights: SSE progress updates, key-file sampling, architecture diagrams, learning paths, and Markdown reports

[GitHub](https://github.com/dakjdakd/OpenConstellation)

A knowledge graph and visual exploration platform for AI ecosystem research.

- 🎯 Role: Product architecture and full-stack development
- 🧰 Stack: React, D3, Express, Zustand, DeepSeek API
- ✨ Highlights: Interactive graph canvas, entity and relationship model, GitHub import, JSON-backed store, and human review gate

- 🧰 Stack: React, Doubao Ark, OpenAI SDK, Recharts, LocalStorage
- ✨ Highlights: Image upload, biomarker extraction, health dashboard, trend charts, and demo mode
